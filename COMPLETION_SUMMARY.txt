## 🔌 API Endpoints (16 Total)

All endpoints are working and can be tested at: **http://localhost:8000/docs**

### Authentication
- `POST /auth/login` - JWT token authentication

### Maintenance Tasks
- `GET /tasks` - List tasks with filters
- `GET /tasks/{task_id}` - Task details
- `POST /tasks/calculate-priorities` - Priority recalculation

### Train Schedule
- `GET /trains` - Train schedule
- `GET /trains/corridors` - Corridor list
- `GET /trains/block-windows` - Available windows
- `GET /trains/goods-forecast` - Goods forecasts

### Block Planning (HERO)
- `POST /blocks/generate-plan` - **Full optimization pipeline**
- `GET /blocks/plans` - List optimization runs
- `GET /blocks/plans/{id}` - Run with blocks
- `GET /blocks/optimized` - Optimized blocks

### Simulation & Analytics
- `POST /blocks/simulate-scenario` - Train conflict simulation
- `GET /analytics` - Analytics + metrics

### Data Import
- `POST /import/load-demo-data` - Seed synthetic data
- `POST /import/csv/tasks` - Upload tasks CSV

## 💾 Database Status

**Supabase Configuration Required (User Action Needed)**

The system is ready but requires:

1. **Create Supabase Account:**
   - Go to https://supabase.com
   - Sign up (free tier available)
   - Create new project

2. **Configure Database:**
   - Run `backend/db/schema.sql` in Supabase SQL editor
   - Creates 8 tables with proper relationships

3. **Add Credentials:**
   - Copy Project URL from Supabase
   - Copy anon key from API settings
   - Copy service_role key from API settings
   - Add to `backend/.env`:
     ```
     SUPABASE_URL=https://xxx.supabase.co
     SUPABASE_KEY=your-anon-key
     SUPABASE_SERVICE_KEY=your-service-role-key
     ```

4. **Test Connection:**
   - Click "Load Demo Data" on dashboard
   - If successful, data appears in Supabase
   - All API calls will now work

## 🐛 Troubleshooting

### "Load Demo Data" fails
**Issue:** Database not configured  
**Fix:** Set up Supabase (see above) and add credentials to backend/.env

### "Generate Plan" returns no results
**Issue:** No tasks in database  
**Fix:** Click "Load Demo Data" first

### Frontend shows connection refused
**Issue:** Backend not running  
**Fix:** `cd backend && python run.py`

### Port 8000/3000 already in use
**Issue:** Services still running from before  
**Fix:**
```bash
# Kill process on port 8000
netstat -ano | findstr :8000
taskkill /PID <PID> /F
```

## ✨ Special Features

### 🤖 Priority Engine
Transparent, explainable scoring based on:
```
Score = 0.30×criticality + 0.25×urgency + 0.20×safety_risk + 0.15×asset_importance + 0.10×overdue
```
Range: 0.0–1.0 (CRITICAL > 0.80, HIGH 0.60–0.79, MEDIUM 0.40–0.59, LOW < 0.40)

### 🎯 Compatibility Engine
Intelligently groups tasks that can be combined:
- Same corridor ✓
- Location proximity (15 km radius) ✓
- Safety rule compatibility ✓
- Department coordination ✓
- Duration constraint fit ✓

### ⚡ OR-Tools Optimizer
Google's CP-SAT solver optimizing for:
- Minimize total block hours
- Minimize number of separate blocks
- Minimize train conflicts
- Maximize task completion
- Maximize multi-department coordination

### 📊 Analytics
Compares:
- **Before:** Manual/departmental scheduling
- **After:** Gatimaan optimized planning
- Shows: Hours saved, blocks reduced, conflicts avoided

### 🔄 Conflict Simulation
Demonstrates system resilience:
1. Select a block
2. Simulate unexpected train
3. System detects conflict
4. Auto-reschedules maintenance
5. Shows before/after
